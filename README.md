# Chekskan — Сканер расходов

Android-приложение для сканирования чеков и контроля расходов.

Что есть:
- камера и добавление фото чека из галереи;
- русский OCR Tesseract + английский резервный язык;
- распознавание многострочных товарных позиций;
- отдельное определение цены за единицу и стоимости товара;
- определение алкоголя, включая пиво;
- автоматический поворот планшета горизонтально/вертикально;
- экспорт расходов в Excel-совместимый файл;
- иконка «чек + лупа».

Сборка APK:
GitHub Actions автоматически собирает debug APK при push в main или вручную через Actions → Build APK → Run workflow. После завершения запуска скачайте artifact Chekskan-APK.

Версия: 2.3.
